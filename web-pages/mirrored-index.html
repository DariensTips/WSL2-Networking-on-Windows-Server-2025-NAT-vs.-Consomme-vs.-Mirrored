This page is served by Fedora 45 running in WSL2 on Windows 11 26H2.

The WSL2 networking mode is Mirrored.

Mirrored networking is a WSL2 networking mode that mirrors the Windows host's network interfaces into the Linux environment. It enables direct access to Linux services from the local network without a manually configured port proxy, provided the application's listening settings and applicable firewall rules permit the connection.
