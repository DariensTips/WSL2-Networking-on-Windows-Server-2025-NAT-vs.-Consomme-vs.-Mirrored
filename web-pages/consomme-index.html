This page is served by Fedora 45 running in WSL2 on Windows Server 2025.

An interesting change is that we are now using WSL2 Consomme networking mode.

Consomme networking is a WSL2 user-mode Network Address Translation (NAT) implementation that translates Linux network traffic into Windows host socket operations. It tracks listening ports in Linux and can automatically relay incoming connections through Windows host sockets to Linux services, without a manually configured port proxy, provided the application's listening settings and applicable firewall rules permit the connection.
